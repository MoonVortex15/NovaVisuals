NOVA VISUALS v2 — Fabric 1.21.4 (Java Edition)

Сборка:
  1) JDK 21.
  2) Открой папку в IntelliJ IDEA (Open -> build.gradle) -> Gradle -> Tasks -> build -> build
     или в терминале (Gradle 8.12+):  gradle build
  3) Мод: build/libs/novavisuals-1.0.0.jar
  4) В .minecraft/mods вместе с Fabric API 0.119.2+1.21.4 (Loader 0.16.10+).
  Тест из IDE: gradle runClient

Клавиши: Right Shift — меню, C (зажать) — Zoom. Настройки сохраняются в config/novavisuals.properties
